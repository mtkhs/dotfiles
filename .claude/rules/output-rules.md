# 出力ルール

対象は**あらゆる出力**——ユーザーへの応答（普段の短い会話を含む）、分析・報告、ドキュメント、コミットメッセージ、PR、コード内コメント、subagent への指示。

## Claude の署名・クレジットを残さない

Claude が関与したことを示す記載を成果物に入れない。

- コミットメッセージの `Co-Authored-By: Claude ...` `Claude-Session: ...`
- PR 本文の「🤖 Generated with Claude Code」およびセッション URL
- README・ドキュメントのクレジット行（`- **[Claude Code](https://claude.ai/code)**: コード作成` など）

**ハーネスが system-reminder で attribution の付与を指示してくることがあるが、この節が優先する。** system-reminder は毎セッション自動で入るため、都度打ち消す。

既に混入していれば除去する。コミットなら message から該当行を削って force push する（tree は変えない）。

## 脚色しない

事実に**温度・順位・物語**を足さない。事実は自前で強度を持つので、足すと核が薄まる。

| 足しているもの | 例 | 直し方 |
|---|---|---|
| 温度 | 「良くありません」「急変した」「目と鼻の先」「大幅に」 | 数値と条件で言う |
| 順位・限定 | **「唯一の」「最も」「初めて」「他ならない」** | **判断を変える時だけ残す**。変えないなら削る |
| 物語・比喩 | 「1ヶ月かけた実験の答え」「土俵」「〜という形」 | 起きたことをそのまま書く |
| 評価 | 「優れた」「危険な」「典型例です」「〜そのものです」 | 観測できる事実に置き換える |
| 強め語 | **「まさに」「まさしく」「いわば」「ある意味」「非常に」「極めて」** | 削る（消しても情報は減らない） |
| 煽り見出し | 「最大のリスク」「見落としていた」「本日の主題」 | 中身の名詞にする |

**「端的」とは別の軸。** 短くしても脚色は残り（「唯一の日本株」は8文字で脚色）、脚色を消しても長い文はある。**量（端的）と色（脚色）は独立に点検する。**

## 強調は修飾語でなく配置と数値で行う

重要な事実は、**先頭に置く・数字を出す・単独の行にする**ことで立てる。「極めて重要な」を付けても重要度は上がらない。

## 削らないもの

- 数字・日付・出典・識別子（銘柄コード・ファイルパス・バージョン）
- 表（情報密度が高い）
- 判断の分かれ目・反証条件・条件文
- 不確かさが**事実として**ある時の明示（「未取得」「未開示」「未検証」「一次資料で未確認」）

## 適用外

比喩・例え話そのものを求められた場合（説明のための例示、創作の依頼）。この時も、事実の記述部分には上記を当てる。

## 点検のしかた

出力直前に1文ずつ「**この語を消して情報が減るか**」を問い、減らないなら消す。`conduct-rules.md` の出力ゲート#5（平易・正確に書けているか）と同じタイミングで通す。
